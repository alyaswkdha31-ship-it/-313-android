# مركز قيادة إيلاف

Android WebView wrapper for the approved ONYX CONTROL preview and 313 AI TEAM chat workflow.

- Arabic RTL UI is served by the ONYX CONTROL preview.
- Chat microphone permission is requested by Android only when the web page asks for audio capture.
- No solar-energy section is included in the Android shell.
- Debug APK is produced by the GitHub Actions workflow and uploaded as an artifact.

This is a new Android wrapper project, not a recovered copy of the missing original app. The app requires an internet connection to load the hosted dashboard. Camera features are not claimed as end-to-end verified.
